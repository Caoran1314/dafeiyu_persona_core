# 大肥鱼人格内核

给机器人一个**稳定的性格向量**：一轮对话里任一维度最多变化 ±0.12，
内核强度低于 0.15 就拒绝这次修改，核心区带签名只读。

## 六维

温柔 / 粘人 / 直率 / 敏感 / 爱玩 / 独立，各自 0~1。

## 命令

| 命令 | 作用 |
|---|---|
| `/人格看` | 六维向量、与内核的偏离、累计驳回次数 |
| `/人格模拟 negative 1.0` | 模拟一次事件对性格的影响 |
| `/人格重置` | 回到内核基线 |

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enable` | true | 开关 |
| `inject` | true | 是否自己写进提示词（交给 mindcore 装配时关掉） |
| `max_dp` | 0.12 | 单轮单维最大变化 |
| `core_floor` | 0.15 | 内核强度保底 |
| `delta_mode` | heuristic | `heuristic` 按事件推；`model` 让她自己提（多一次模型调用） |

## 注意

- 不读不写任何记忆库
